# TO Yobanka Carranza

Sitio informativo de una página para la terapeuta ocupacional Yobanka Carranza. Diseño original, adaptable a móviles y enfocado en terapia ocupacional en Caracas, integración sensorial, selectividad alimentaria, autonomía y orientación a familias.

## Archivos

- `index.html`: contenido, metadatos SEO y datos estructurados de negocio local.
- `styles.css`: estilos adaptables.
- `script.js`: navegación móvil y año automático del pie de página.
- `robots.txt` y `sitemap.xml`: archivos base para rastreo.

## Antes de publicar

1. Sustituir `https://www.ejemplo.com/` en `sitemap.xml` y añadir `rel="canonical"` con el dominio definitivo.
2. Confirmar que los enlaces de Instagram y los métodos de contacto son los que Yobanka desea publicar.
3. Confirmar si la atención online está disponible para todas las consultas y edades; el texto invita a consultar la modalidad adecuada.
4. Añadir una página de privacidad si se incorpora un formulario o herramientas de analítica.

La dirección exacta del consultorio no se incluye en el sitio, de acuerdo con la información recibida.
